📘 Quick reference: tree vocabulary
  • Root — the top node, with no parent.
  • Parent / child — a node directly above/below another.
  • Siblings — children of the same parent.
  • Leaf — a node with no children.
  • Depth of a node — number of edges from the root to it.
  • Height of the tree — depth of its deepest leaf.
  • Size — total number of nodes.
  • BST rule — every left descendant < node < every right descendant.
